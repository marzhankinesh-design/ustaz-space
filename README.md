# USTAZ SPACE — бастапқы серверлік нұсқа

Бұл жоба Sage Calm дизайнын сақтайды және браузердегі localStorage тіркелуінің орнына Express + PostgreSQL серверлік аутентификациясын қолданады.

## Қажет болады
- Node.js 20 немесе одан жаңа
- PostgreSQL деректер базасы
- Терминал

## Жергілікті іске қосу
1. PostgreSQL-де деректер базасын жасаңыз.
2. `database/schema.sql` файлын сол деректер базасында орындаңыз.
3. `.env.example` файлын `.env` деп көшіріп, `DATABASE_URL` және `SESSION_SECRET` мәндерін енгізіңіз.
4. Терминалда жоба бумасына өтіп, `npm install` орындаңыз.
5. `npm start` орындаңыз.
6. Браузерде `http://localhost:3000` ашыңыз.

`SESSION_SECRET` үшін ұзын, кездейсоқ құпия мән қолданыңыз. `.env` файлын GitHub-қа жүктемеңіз.

## Қазір жұмыс істейтін серверлік негіз
- тіркелу: `POST /api/auth/register`
- кіру: `POST /api/auth/login`
- ағымдағы аккаунт: `GET /api/auth/me`
- шығу: `POST /api/auth/logout`
- денсаулық тексерісі: `GET /health`

Құпиясөздер bcrypt арқылы хэш түрінде сақталады. Сессиялар PostgreSQL-де сақталады. Жоба әлі жариялауға толық дайын өнім емес: HTTPS/өндірістік орта баптауларын тексеру, құпиясөзді қалпына келтіру, email растау, CSRF қорғанысын толық енгізу, профильді өңдеу API-ы және қалған мәзір модульдері келесі кезеңдерде жасалуы тиіс.
